# ComfyUI 워크플로 라이브러리

Comfy Cloud에서 쓰는 ComfyUI 워크플로 JSON 모음과, 다른 컴퓨터에서도 Claude가 같은 규칙으로 워크플로 작업을 하게 해 주는 스킬을 담은 저장소입니다.

| 경로 | 내용 |
|---|---|
| `workflows/` | 워크플로 JSON 47개와 시작 안내 `00_어떤걸쓸까.md` |
| `skills/comfyui-workflow/` | Claude가 워크플로 작업 때 읽는 규칙과 검사 도구 |
| `install.sh`, `install.ps1` | 위 스킬을 이 컴퓨터에 설치하는 스크립트 |
| `skills/comfyui-workflow/tools/` | 워크플로 JSON 검사, 모델 최신 확인, 공개 전 검사 도구 |
| `reports/` | 모델 최신 확인, 워크플로 점검, Cloud에 가져올 모델 목록 |

**`12_NSFW` 폴더는 공개 저장소에 포함하지 않습니다.** `.gitignore`로 제외되어 있습니다. `workflows/00_어떤걸쓸까.md`에 이 폴더 줄이 보여도 저장소에는 없습니다. 없어도 오류가 아닙니다.

## 어떤 워크플로를 쓸까

파일 앞 `01`, `02`는 **같은 폴더 안 순서**입니다. 01부터 써 보세요. 파일 끝 초는 576x1024·73프레임 영상으로 Comfy Cloud에서 잰 시간입니다. 시험 클립 1건 기준이고, 이번 수정 전 파일의 기록이라 다른 영상에서는 순서가 달라질 수 있습니다.

### 영상 속 무언가를 바꾸고 싶다 → `01_영상편집_VFX`

**지금 손에 뭐가 있는지**로 폴더를 고르면 됩니다.

| 내가 가진 것 | 폴더 | 특징 |
|---|---|---|
| 글로 된 지시뿐 | `01_글로만_지시` | 가장 간단합니다. 얼굴·배경은 조금 달라집니다 |
| 참고 사진(옷, 제품 등) | `02_참고사진으로_교체_마스크없음` | 마스크 없이 사진대로 바꿉니다 |
| 이미지 툴로 고친 첫 프레임 | `03_첫프레임_고쳐서_전체에_전파` | 원하는 결과를 먼저 그려서 영상 전체로 퍼뜨립니다 |
| 바꿀 영역의 마스크 | `04_마스크로_영역지정_원본보존` | 원본이 가장 잘 남습니다. 마스크는 `08_로토·마스크·패스`로 만드세요 |

어떤 폴더든 하드컷이 있는 영상은 컷마다 결과를 꼭 확인하세요. 얼굴·배경을 지키는 것이 가장 중요하면 `04` 폴더부터 쓰세요.

### H3·LTX 영상편집 성능 순서

파일 이름 끝의 `H3-01`, `LTX-01`은 폴더를 넘어선 모델별 순서입니다. 같은 시험 영상(검은 니트→빨간 패딩) 기준이고, 차이 값은 원본 대비 평균 차이라 낮을수록 원본이 잘 남습니다. 유지율은 편집이 끝 프레임까지 남은 비율입니다.

| H3 | 필요한 것 | 머리·손 차이 | 배경 차이 | 유지율 | 시간 | 한 줄 평 |
|---|---|---|---|---|---|---|
| 01 Ripple | 고친 첫 프레임 | 6.6~7.7 | 3.2~3.7 | 81~88% | 37초 | 가장 균형이 좋습니다 |
| 02 Pika 사물교체 | 제품 사진 | 7.7~10.0 | 5.4~6.6 | 보온병 73프레임 유지 | 50초 | 사물 교체 시험 값입니다 |
| 03 VFX | 참고 사진 | 14.0~15.0 | 4.7~6.1 | 82~89% | 60초 | 의상·사물 모두 됩니다 |
| 04 FFP | 고친 첫 프레임 | 13.9~15.7 | 4.2~7.0 | 88~93% | 39초 | 편집 유지가 가장 강하지만 화면이 부드러워집니다 |
| 05 R2V | 글만 | 8.8~10.3 | 5.1~6.3 | 66~68% | 285초 | 보존은 좋지만 편집이 약하고 가장 느립니다 |

| LTX | 필요한 것 | 머리·손 차이 | 배경 차이 | 유지율 | 시간 | 한 줄 평 |
|---|---|---|---|---|---|---|
| 01 인페인팅 | 마스크, 고친 첫 프레임 | 1.4~2.1 | 1.0~1.1 | 72~88% | 18초 | 마스크 밖은 원본을 씁니다. 가장 빠릅니다 |
| 02 Ripple | 고친 첫 프레임 | 6.4~7.0 | 2.5~2.9 | 84~88% | 34초 | 마스크 없이는 가장 좋습니다 |
| 03 EditAnything | 글만 | 12.2~13.8 | 5.3~5.6 | 93~97% | 23초 | 편집은 강하지만 색이 따뜻해지고 병이 흔들립니다 |

시험 클립 1건 기준입니다. 편집 외 작업은 기능이 달라 순위를 매기지 않았고, 폴더 안 번호를 먼저 써 볼 순서로 보면 됩니다.

### 지우기 고르는 법

- 하드컷 1개가 있는 근접 인물 영상 → `01_Pika` (컷마다 빈 배경 사진 필요)
- 멀리 있는 사람·차량 → `02_LTX2.5`
- `03_H3_PersonRemover`는 멀리 있는 1명까지만 됩니다. 가까운 인물은 시험에서 실패했습니다.
- 사람을 지운 첫 프레임이 있으면 `01_영상편집_VFX/03_첫프레임_고쳐서_전체에_전파/03_H3_FFP`로도 지워집니다. 화면이 조금 부드러워집니다.

## 다른 컴퓨터에서 설치

Git과 Claude Code가 있어야 합니다.

```sh
git clone <이 저장소 주소>
cd <저장소 폴더>
./install.sh
```

Windows PowerShell에서는 `powershell -ExecutionPolicy Bypass -File install.ps1`을 실행합니다.

스크립트는 `skills/comfyui-workflow` 폴더를 `~/.claude/skills`에 복사합니다. `~/.codex`가 있으면 `~/.codex/skills`에도 복사합니다. 설치된 스킬에는 이 저장소의 위치가 기록되어 Claude가 `workflows/`를 찾아 씁니다. 저장소 폴더를 옮기면 다시 실행하세요.

설치가 끝나면 Claude에게 평소처럼 워크플로 작업을 요청하면 됩니다.

- "이 ComfyUI 워크플로 JSON을 점검해 줘"
- "H3로 마스크 없이 참고 사진 교체하는 워크플로를 새로 만들어 줘"
- "지금 쓰는 LTX 모델이 최신인지 확인해 줘"

Comfy Cloud 계정이 바뀌었거나 처음 쓰는 계정이면 [reports/Cloud_가져올_모델.md](reports/Cloud_가져올_모델.md)대로 없는 모델을 가져오세요.

## 업데이트

```sh
git pull
./install.sh
```

스크립트는 스킬 폴더 하나만 바꾸며 여러 번 실행해도 됩니다.

## 검증 상태

**이번 수정본은 Comfy Cloud에서 불러오거나 실행하지 않았습니다.** 지금까지 확인한 것과 확인하지 않은 것은 다음과 같습니다.

**확인한 것**

- 2026-11-09 정적 검사(`skills/comfyui-workflow/tools/validate_workflow.py`): 공개 47개 파일 오류 0, 경고 0.
- 원본과 수정본을 자동 비교: 노드 id, 타입, mode, 링크가 모두 같습니다. 기본값이 바뀐 곳은 [점검 보고서](reports/2026-11-09_워크플로_점검.md)에 전부 적었습니다.
- 2026-11-09 Cloud 목록 대조(실행 없음): 라이브러리가 쓰는 노드 타입 201개는 모두 있습니다. 모델 이름 99개(12_NSFW 포함) 중 81개가 있고 18개는 없습니다. 18개 중 공개 저장소에 필요한 것은 10개입니다.
- 2026-11-09 모델 최신 확인: [모델 최신 확인 보고서](reports/2026-11-09_모델_최신확인.md)

**라이브러리의 기록**

- 파일 이름의 초, 위 성능 표, 각 파일 안내 노트의 시험 결과는 이번 수정 전 파일을 2026-11-07~08에 시험한 기록입니다. 대부분 시험 클립 1건 기준입니다.
- `90_유료API·스토리보드_미실행`은 Cloud에서 돌려 본 기록이 없습니다.

**확인하지 않은 것**

- 이번 수정본의 Cloud 불러오기와 실행, 화면 배치 확인.
- 새 모델 후보의 실행과 품질. 지금은 파일 구조와 날짜만 확인했습니다.
- 기본 입력이 시험 파일인 일부 워크플로가 지금 계정에서 열리는지.
